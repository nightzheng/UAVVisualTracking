## 材料点语义检查

| 点 | 当前可评性 | 人工须解决的问题 |
|---|---|---|
| p000 | 待确认几何参考定义 | 轴心是几何参考，不能描述为某个叶片材料点；独立点定位判据是什么 |
| p001 / A | 未确认持续材料对应 | 查询在近叶尖均匀红色区域，不能自动以精确叶尖或色带边界替代 |
| p002 / B | 同上 | 塔身附近外观重叠时是否仍能辨认同一材料点；区分可见、遮挡和出画 |
| p003 / C | 同上 | 三片周期重复、关联跳变后如何维持原始 C 身份，而不是按空间方位重命名 |

如果旧查询无法持续辨认，标 uncertain / 不可评价；允许只评价少量定义与复核明确的点帧。若另选清楚的材料标记，需新 ID/查询配置和同输入两模式结果，不能把新点 GT 作为旧点真值。

## 首批人工复核清单

不要求先标满 480 条。先解决点定义，再按代表帧与事件两层取样；每条有效 GT 都应直接来自原帧及人的复核。建议清单已另存 `experiments/weekly/20261013_manual_review_queue.csv`，它只是待办，不是 GT 文件。

| 时段/点 | 问题 | 依据与标签限制 |
|---|---|---|
| 0 / 全部 | 定义 A/B/C 的具体材料位置与 p000 几何中心 | 不允许从查询像素强行推断可持续语义 |
| 0,10,…,110,119 / 可辨认点 | 建立覆盖整个片段的身份链 | 首批稀疏标注不代表全 120 帧真值 |
| 20,28,36 / p002 | GT 是否可见？真实遮挡还是背景投影混淆？ | Stage 1 C01 只是预测可见性下降候选 |
| 54,61,62,68 / p001 | 165.165 px 跳变是否转向另一片叶片？ | Stage 1 C02；不得直接写已确认 ID switch |
| 56,57,62 / p003 | 关闭网格的 178.995 px 跳变对应哪个材料身份？ | Stage 1 C04 |
| 83,90,105,119 / p001–p003 | 可见布尔值返回是否恢复原材料身份？ | 需人查看连续原视频，不能用预测位置猜标签 |
| 18–22、50–56、61–64、83–88 / p001 | 新裁剪中的离画/返回候选与大跳变 | 来自本周无 GT 诊断；先在源帧定义材料身份，再判裁剪视域 |

人工标注人与复核人填写身份和实际时间；优先独立复核，同人第二遍复核应披露。GT 冻结后再显示预测做案例关联复核，不反向改 GT。定量评价以审查后的条目为分母，零覆盖指标保持 null。

## 有效 GT 到达后的执行路径

复用 `scripts/evaluate_stage1.py`、`compare_stage1_gt.py`，比较正式四点、同一输入、同一权重、同一 GT 的 on/off。少量稀疏有效条目足以启动有边界的评价，不等待全部 480 条。记录每点已标源帧、GT 可见分母、定位有限覆盖率、可见性混淆矩阵、人工身份案例与稀疏事件区间；不推断全时段恢复率。

局部先导需要将源 GT 明确变换到裁剪：`p_crop=p_source_processing−(x0,y0)`。对源 GT 可见且身份已确认的点，裁剪外位置可几何派生为 out_of_frame；不能对源视频未标的材料位置新增真值。不同裁剪定位误差还应映回公共源像素尺度，原图误差通过已声明的 resize 映射计算。现有 evaluator 不能自动把 960×540 全景 GT 当作裁剪 GT 使用；必须显式派生并保存来源哈希/ROI/映射再评价。

当前冻结的阈值 2/5/10/20 是 960×540 处理像素，不是 TAP-Vid 的 256×256 阈值。未来真实 GT 评价可附原图误差（本视频均匀 2×映射，EPE 为处理误差的 2 倍），归一化误差需显式按两个轴的尺寸变换后重新计算；未实现官方 TAP-Vid AJ，不将现有 F1 或正确率冒称为 AJ。

目前只保留 [V0_ERROR_ANALYSIS.md](V0_ERROR_ANALYSIS.md) 与本周先导的跳变、预测可见率/越界诊断。没有真实精度、身份恢复率、最佳配置或局部任务通过结论。
