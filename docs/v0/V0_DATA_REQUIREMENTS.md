# 真实局部叶片数据需求（Stage 1）

2026-10-13。现有 wind_turbine.mp4 是全转子开发演示，不能作为近距离部分可见巡检验收。当前没有冻结测试集，没有公开数据集授权结论。下面是待采集/登记方案，不要求本轮采齐。

## 场景覆盖

| 因素 | 最小覆盖设计 | 需记录 |
|---|---|---|
| 局部视场 | 只出现一段叶片，轮毂不可见；叶根/叶尖分别部分出画 | 可见部位、可见长度比例、遮挡原因、材料点出入画 |
| 持续旋转 | 各片叶片身份可连续追溯；有缓慢及变化速度片段 | 视频 PTS、角速度是否可独立测量、未能测量时标 unknown |
| 相机运动 | 固定相机一组；相机平移/姿态变化一组 | 相机元数据、稳定背景点是否可见、IMU/时间同步可用性 |
| 尺度变化 | 同点在近/远或沿画面深度变化，包含明显放大/缩小 | 点局部像素尺度、分辨率、焦距/变焦、裁剪记录 |
| 材料可辨性 | 叶尖、色带边界、可辨识内部纹理；无纹理片段独立分层 | 材料点定义与近景参考、不确定性、三叶片 ID |
| 可见性干扰 | 真遮挡、出画、运动模糊、阴影/高光、低纹理 | 分开标注原因，不能用预测可见性反推 |
| 返回事件 | 遮挡/出画前后有足够原始上下文，不止返回单帧 | 连续 GT 覆盖、再次出现的材料身份、未知间隔 |

优先小规模、权属清楚的固定机位局部叶片视频作为开发数据，再加入移动相机和尺度变化。不要为了数据采集进入 V2 跟飞或飞控实现。裁剪现有全景可检验裁剪/坐标接口，但须标 `derived_crop_proxy`，与真实近距离局部视场分开；裁剪不会创造近景纹理、真实运动模糊或局部身份线索，不能充当目标场景通过证据。

建议首批开发集按“静止/移动相机 × 根/中段/尖端局部”组织少量独立片段，时长保证所需遮挡/返回事件前后上下文；数量根据真实可标注程度决定，不承诺未经收集的样本数。每片段优先 3–6 个真正可辨认材料点，另设可用非旋转参照；无对应物理点则按不确定条目处理。

## 开发与冻结测试隔离

当前视频及已观察的失效片段属于开发数据。冻结测试应来自独立原始视频，优先不同风机、拍摄会话/视角与机位。以原始视频/会话分组，禁止同一视频相邻帧或不同裁剪分别进入开发/测试。训练/微调本轮不开展，仍预留未来数据划分记录。

冻结前完成人工定义、标注及复核，登记不可标注比例、GT 可见/不可见分母、各困难因素覆盖；记录测试名单、源文件 SHA、标注 SHA、协议版本与冻结日期。测试选择与阈值在算法比较前确定。开发已调参片段不能重新包装为测试；未标时段不计成功恢复率。保持原始素材访问受限，派生帧/图像同样不是自动允许公开的数据包。

## 视频登记与 Pexels 来源跟进

登记清单仍为 `DATA_REGISTER.json`。每条至少保存：原文件名与 SHA256、分辨率、FPS/PTS、总帧数、原始页面 URL、素材作者、平台内容 ID、下载日期/人及原始下载记录、许可/条款页面与核查日期、裁剪/转码操作、实验使用记录、GT 状态和数据划分。未知字段为 null；来源平台用户已确认 Pexels，不回退为完全未知来源。

本轮再次查阅两个旧候选页面及公开搜索。风机候选 9403173 的页面显示作者 Steve B、4K、25 FPS、1:19，与本地 1080p/29.97/26.49 秒不同；这不足以建立同一素材身份，作者不能写入本地素材正式 author 字段。人物候选 6000644 的页面显示 Sam Lion、4K、23.98 FPS、0:10，也没有本地下载/剪辑记录证明对应关系。候选作者仅写在独立 `SOURCE_FOLLOWUP_STAGE1.json` 的候选元数据中；正式 source_url/author/download_record 继续为 null，不虚构来源。

下一步应由素材持有人提供下载历史、原始 URL 或未改名文件/浏览器记录，并按画面序列、长度、剪辑操作和本地 SHA 逐条验证。未经授权不读取私人浏览历史。单凭风机/街景标题或 FPS 相近不能确认。
