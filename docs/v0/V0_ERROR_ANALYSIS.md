# V0 失效证据与归因（Stage 1）

2026-10-13。本轮使用新执行的真实离线 CoTracker3 预测：`stage1_20261013_controlled/measured_02_on` 与 `measured_03_off`。尚无人工复核 GT，以下为原图与预测的定性检查及数值行为诊断，不是定位精度、身份切换率或已验证恢复率。

## 已观察行为与待验证解释

最明确的异常是叶片轨迹的大幅跳变与随后贴近另一片相似叶片的重关联候选。support on 的 p001 在 61→62 帧移动 **165.165 处理像素**；support off 的 p003 在 56→57 帧移动 **178.995 像素**。对照原图，叶片呈连续旋转，预测的关联对象存在不连续变化。该现象足以安排人工身份复核；其具体材料点身份切换还没有人工 GT 证明，不能把“点位于另一条叶片附近”直接当作已复核 ID switch。

另一项已由数组证实的行为：预测不可见时仍输出有限坐标。网格开 p001/p002/p003 分别有 31/92/34 个不可见帧，所有这些帧仍有有限坐标；网格关分别为 8/69/12 帧，也全部有限。坐标继续输出是接口行为，不能因此认定点仍被正确跟踪。可见性布尔值由官方 0.9 阈值产生，不是轨迹身份保证。

## 八项归因审查

1. **初始位置**：原帧中三点靠近红色叶片末端，并非已确认的精确叶尖。均匀色块内任意像素难以持续认作同一材料位置。轴心是几何参考；完整点定义与查询对应关系需要人确认。
2. **弱纹理与背景**：末端内部弱纹理、天空和森林背景提供少量稳定独特线索，可产生匹配歧义。当前只能列为解释候选；没有纹理受控消融或 GT 分层证据证明它是主因。部分原图中的失效坐标仍在叶片附近，因此不把所有异常统一说成“天空背景锁定”。
3. **三片周期重复**：C02/C04 的跳变与相似叶片重关联最值得优先复核。需完整材料身份链证明，不能按当前空间上/左/下位置重新赋 ID。
4. **遮挡/出画/速度变化**：C01 有塔身重叠候选。现有片段多为全转子视场，GT 遮挡、真实出画与角速度变化尚未标注；不可从预测可见性推断真实遮挡，也不能提前归因转速变化。
5. **不可见坐标**：已证实继续输出有限坐标，统计见上。评价必须保留 GT 可见且预测不可见的定位误差，避免筛掉失败样本。
6. **返回身份**：已整理预测可见返回时刻，未确认任何物理身份恢复。稀疏人工 GT 只能评价已标恢复观察帧，不推断全时段恢复率。
7. **support grid 真实误差**：本轮 on/off 输入、查询、权重相同。缺 GT，真实 EPE、位置正确率和可见性 P/R/F1 均为 null，不决定最佳配置。
8. **坐标映射**：原图→处理图使用 OpenCV 半像素公式 `p'=(p+0.5)*s-0.5`；处理图→官方内部 512×384 使用 align_corners 比例 `x'=x*511/959, y'=y*383/539`，返回使用反比例。两者不能混用。本轮数值往返误差分别为 0 与 5.68e-14 像素，真实查询帧最大差 6.10e-5。接口输出已返回 960×540。官方强制将查询帧坐标覆盖为查询且设可见，故该帧一致不能证明模型准确。后续人工对齐仍独立校验视频 SHA/帧号/PTS/点 ID/尺寸。

## 人工 GT 后的错误分类

冻结 GT 后可分：可见但位置偏离、GT 不可见却预测可见、GT 可见却预测不可见、非有限输出、确认关联到另一物理点、几何返回但材料身份未恢复、出画/遮挡期间预测行为、查询点本身不可辨认。每个类别须有统计分母和可复核案例；不将不同类别自动归结为模型结构问题。当前先解决可评价性和身份协议，不启动结构修改、训练或 V1。
