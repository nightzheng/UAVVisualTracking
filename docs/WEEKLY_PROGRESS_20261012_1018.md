# UAVVisualTracking 本周科研进展

周期：2026.10.12–10.18；记录截至 **2026.10.13**，10.14–10.18 仍属计划，不写成已完成事实。重点是 V0 部分可见局部持续跟踪和 V1 可验证的相机补偿实验条件。

## 已完成成果

冻结 CoTracker3 GPU 离线基线 **V0-offline-wind120-20261013-r1**：官方源码/权重、120 帧输入、四个旧查询、两种 support 策略、未来权限和评价口径均有指纹。Stage 0/1 历史运行保留。冻结是工程协议，不是材料身份、真实精度或冻结测试集通过证明。

本周新增完整画面、带地面背景局部、局部天空与紧局部四个视场。每组同一 p001 初始化，网格开/关共 **8 组保存的真实 GPU 离线预测**，另两次排除暖机。输出帧数、结果哈希及裁剪/原图坐标映射核验通过，CSV 原图坐标最大差 0。只有 **1 个独立源视频**，裁剪不等于独立近景采集。

紧局部在原帧 20 开始预测不可见；局部天空在 52/53 帧开始预测不可见。地面背景局部仍有 235.515 / 169.982 px 最大预测跳变，完整单点对照也有 189.825 / 166.987 px 跳变。视场改变带来明显轨迹差异，但不能证明哪个配置更准确，或将较晚预测不可见称为更可靠。

V1 完成坐标方向、逆向、增量累计、有效性及缺口传播契约；三类已知 H 共 360 个数学校验点帧，最大求逆误差 <3.5e-13 px。**未实现真实背景运动估计，未验证真实相机运动或米制恢复。** 工程测试 **37/37 通过**（既有 27 + 新增 10），测试样例不是风机人工 GT。

## 判断与问题

人工复核 GT 仍为 **0/480**。均匀叶片末端的可见位置不自动定义可持续材料点。人员须先确认点语义，再标少量代表帧/关键帧并复核；本周不以标满 480 条为唯一完成条件。没有真实 EPE、准确率、身份恢复率或最佳 support 配置结论。

先导弥补“算法仅看全转子”的输入缺口，尚未解决独立真实近景、材料身份和相机参考缺口。裁剪同时改变尺度、内部宽高比映射和背景，不能单因素归因。相似叶片再次进入局部画面后的身份仍须人工连续原视频复核。

二维补偿是图像参考像素坐标归一化，不能直接称三维自运动恢复。已知 H 求逆通过不代表能从背景正确估计 H；无背景、强视差、多动态或不可逆时须显式失败，不用滤波强制唯一结果。Pexels 单条 URL/作者/下载记录继续待登记，不虚构来源、不批量抓取或公开素材。
