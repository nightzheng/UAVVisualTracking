## 结果与问题

- 原始 120 帧已导出，可编辑 JSON/CSV 和网页工具均无预测辅助位置。三片叶片 A/B/C 固定身份；旧查询的具体材料点对应关系须人工确认。均匀红色末端不自动等于可持续识别的叶尖，轴心只作几何参考。
- 真实 GPU 离线模型本轮新运行 10 次，2 次暖机排除，网格开/关各 4 次有效计时，顺序 ABBA BAAB。中位时间 3.739815 / 3.680110 秒（32.087 / 32.608 FPS）。差异小且样本少，不能据此选择最佳配置；更高预测可见率也不能替代准确率。
- 确认预测不可见时仍保留有限坐标；发现开网格 p001 的 165.165 px 单帧跳变及关网格 p003 的 178.995 px 跳变。图像提示相似叶片重关联，尚未用人工材料身份 GT 确认 ID switch 或恢复。
- 独立采样 168 条、0 错误。计时轮 Windows 进程专用用量峰值 12.970 GiB、共享 7.955 GiB，同时 PyTorch allocated 17.585 GiB、reserved 20.582 GiB。这些指标含义不同；不能称超过物理 16GB 的 dedicated 驻留，未测逐分配迁移/驻留真值。
- 坐标映射往返与真实查询帧输出校验通过；官方查询帧强制覆盖，因此不作为模型准确性证据。评价检查视频/帧/时间/点身份/尺寸，未标条目不插值。
- 完整测试 **27/27 通过**，包含既有 19 项和新增 8 项评价门槛/稀疏统计/事件检查。虚构算术测试样例仅验证代码，不是风机 GT。
- Pexels 风机/人物原始页面及作者仍未确认。记录候选页面元数据及不匹配证据，正式字段保持 null；原始素材未纳入 Git。

## 下一步算法选择建议与停止边界

先人工确认点定义，标代表帧和失效加密帧，完成原图复核，冻结同一 GT，再评价两种配置和逐例人工身份复核。若旧查询无法对应可持续辨认材料点，标记不可评价，另选有独特外观的点并以相同新查询重新对比。

若 GT 证实三片周期歧义/身份切换主导，优先讨论材料身份约束与恢复验证；若弱纹理点定义主导，优先改善可辨识点选取与数据；若独立相机运动证据主导，再审阅 V1 计划。当前数据不支持直接宣布 support grid 最佳、不支持直接启用完整 V1、DA3/SAM 2 或训练。

本轮保留 Stage 0 运行，原小组只读；未提交 Git、未推送或发布远程仓库，未修改官方模型、未启动大规模实验或 V2。阶段停在审阅与真实人工 GT 的交接处，不能标记完整通过。
